Changes include the displayed mod name, mod ID, configuration title and filename, log prefix, resource filenames, artifact names, and build/documentation setup. The inventory algorithms, compatibility API, and original mouse/inventory artwork come from Mouse Tweaks. The Java package and public API names are retained for compatibility with existing container integrations.

Fabric metadata provides the legacy `mousetweaks` ID as an alias. Install this fork as a replacement for Mouse Tweaks.
